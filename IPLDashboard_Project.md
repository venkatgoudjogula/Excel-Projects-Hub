# 🏏 IPL Dashboard (2008–2025)

## 📊 Project Overview
An interactive IPL Data Analysis Dashboard built using Microsoft Excel to analyze IPL data from 2008 to 2025. The dashboard dynamically displays insights based on the selected IPL season.

## ✨ Features
- 🏆 IPL Winner and Runner-Up
- 🌟 Man of the Season
- 🪙 Toss Decision Winning Percentage
- 🏏 Team-wise Wins: Batting First vs Bowling First
- 🏟️ Venues with the Most Wins
- 🏆 Team-wise Trophy Count
- 🎯 Man of the Match Analysis
- 🎛️ Interactive season selection using slicers
